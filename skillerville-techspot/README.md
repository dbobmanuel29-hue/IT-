# Bobmanuel Portfolio Website

A personal portfolio built with plain HTML, CSS and vanilla JavaScript. The code is grouped into clear files so it is easy to study and edit.

## Folder structure

```text
skillerville-techspot/
├── index.html                 # Homepage
├── about.html                 # Personal introduction and background
├── experience.html            # Education and learning journey
├── skills.html                # Current technical foundations
├── contact.html               # Public links and demo contact form
└── assets/
    ├── css/style.css           # Shared styles, responsive layouts and animations
    ├── js/script.js            # Mobile menu, form validation and reveal animation
    └── images/
        ├── logo.svg            # Personal logo and favicon
        └── profile.jpg         # Profile photograph
```

Open `index.html` in a browser to view the website. No framework, external font, CDN or installation step is required.

## Editing guide

- HTML files contain the page content and shared header/footer.
- `assets/css/style.css` controls colours, spacing, layouts and animations.
- `assets/js/script.js` handles the mobile menu, form check and scroll reveal.
- Replace files in `assets/images/` to change the logo or profile picture.

The contact form is a demonstration only. It validates the fields in the browser and does not send or store messages.
