Personal Portfolio Website

A responsive website designed to introduce me, share my learning journey and show the frontend skills I have practised.

HTML CSS JavaScript Responsive design
01

Page structure

HTML is used to add headings, paragraphs, images, navigation links and form fields.

02

Page styling

CSS is used for the colours, spacing, layout, typography and mobile screen adjustments.

03

Simple interactions

JavaScript controls the mobile navigation and checks the contact form fields.

How it is organised

Simple files, clear purpose.

Each page has its own HTML file. The shared design is kept in one CSS file, while the small interactive features are in one JavaScript file. Images are stored locally in the images folder.

The contact form is for demonstration only. It checks the entered details in the browser; it does not send or save messages.
